# subv

A subtitle viewer for SRT files with timeline scrolling functionality.

## Features

- Load and display SRT subtitle files
- Play/Pause playback with automatic timing
- Interactive timeline with visual progress bar
- Click or drag on timeline to jump to any position
- Keyboard shortcuts for easy navigation:
  - **Space**: Play/Pause
  - **? / ?**: Skip backward/forward 5 seconds
  - **? / ?**: Skip backward/forward 30 seconds
  - **Home**: Jump to start
  - **End**: Jump to end
- Visual cue markers showing subtitle positions on timeline
- Touch support for mobile devices
- Responsive design with modern UI

## Usage

1. Open `subviewer.html` in a web browser
2. Click "Choose SRT" to load a subtitle file
3. Click "Start" to begin playback
4. Use the timeline or keyboard shortcuts to navigate
5. Click "Pause" to pause/resume playback
