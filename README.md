# subv

Simple in-browser subtitle viewer for `.srt` files.

## Features
- Load local SRT files and display cues with large, high-contrast styling
- Play, pause, or resume timing against real time
- Scrub with the new timeline slider or by scrolling anywhere in the stage to move through time
- Live timecode readout and automatic status updates (playing, paused, finished)

## Usage
1. Open `subviewer.html` in a modern browser.
2. Choose an `.srt` file via **Choose SRT**.
3. Use **Start** to begin playback, **Pause/Resume** to control it, or move the timeline/scroll to jump to a specific timestamp.
4. When scrubbing while playing, playback pauses automatically and resumes once you release the slider.
