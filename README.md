# subv

Minimal standalone subtitle viewer for `.srt` files. Load a subtitle file in your browser and control playback without any video source.

## Usage
- Open `subviewer.html` in a modern browser.
- Use **Choose SRT** to load a subtitle file, then press **Start** to begin playback and **Pause** to toggle pause/resume.
- Scrub through time with the timeline slider. You can drag the handle or use keyboard controls when the slider is focused.
- Scroll anywhere over the subtitle stage with your mouse or trackpad to jump backward or forward in time (use `Shift` for medium steps, `Ctrl`/`Cmd` for fine adjustments).
- Watch the live time display to keep track of the current position and total subtitle duration.
